# Tang AI Chat

Tang AI Chat 是一个基于 [NextChat](https://github.com/ChatGPTNextWeb/NextChat) 的聊天应用项目。

## 本地开发

先安装依赖：

```bash
yarn install
```

当前最小开发命令（与 `package.json` 保持一致）：

```bash
yarn dev
yarn build
yarn start
```
